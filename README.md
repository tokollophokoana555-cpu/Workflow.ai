# 🤖 WorkFlow AI

## An Intelligent System for the Future of Work

WorkFlow AI is an intelligent decision-support system
designed to help individuals and teams organize work,
identify project risks and balance workloads.

## Problem

Modern workers and teams often struggle with:

- Managing multiple tasks
- Identifying priorities
- Meeting deadlines
- Detecting project risks
- Balancing workloads

## Solution

WorkFlow AI helps users:

- Create structured work plans
- Identify task priorities
- Analyze project risks
- Detect workload imbalances
- Receive intelligent recommendations

## Features

### 📋 AI Work Planner

Helps users transform project descriptions into
structured work plans.

### ⚠️ Risk Detector

Analyzes the relationship between tasks and
available time to identify potential risks.

### 👥 Workload Analyzer

Identifies workload imbalances between
team members.

## Technologies

- Python
- Streamlit
- Pandas

streamlit run app.py
